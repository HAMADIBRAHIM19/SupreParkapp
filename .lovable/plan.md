# معرفة قاعدة بيانات المستخدمين

## الهدف
توفير استعلام مباشر على الـ Backend لعرض قائمة المستخدمين مع نوع الحساب (حاجز / باحث) وغيرها من البيانات الأساسية.

## الخطوات
1. التحقق من توفر اتصال قاعدة البيانات في الجلسة عبر `psql`.
2. تشغيل استعلام يربط جدول `auth.users` بـ `public.profiles` لإظهار:
   - معرف المستخدم (UUID)
   - البريد الإلكتروني
   - الاسم الكامل
   - اسم المستخدم
   - نوع الحساب (`account_type`: seeker / crew)
   - تاريخ الإنشاء
3. تصدير النتيجة إلى ملف CSV داخل `/mnt/documents/` لسهولة المراجعة.
4. تسليم الاستعلام كمقتطف جاهز للاستخدام المستقبلي دون تكرار.

## الاستعلام المقترح
```sql
SELECT
  au.id,
  au.email,
  au.created_at,
  p.full_name,
  p.username,
  p.account_type
FROM auth.users au
LEFT JOIN public.profiles p ON p.user_id = au.id
ORDER BY au.created_at DESC;
```

## ملاحظات
- هذا استعلام للقراءة فقط؛ لا يتطلب migration.
- البيانات الحساسة (مثل hash كلمة المرور) لا تُعرض.
- إذا أراد المستخدم في المستقبل عرضها من لوحة الأدمن داخل التطبيق، يمكن تحويل الخطوة إلى Edge Function أو صفحة Admin.
