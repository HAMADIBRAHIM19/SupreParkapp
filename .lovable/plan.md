# استخراج بيانات مستخدمي التطبيق

## الهدف
توفير قائمة بجميع المستخدمين المسجلين في التطبيق مع بياناتهم الأساسية (البريد الإلكتروني، الاسم، نوع الحساب، تاريخ التسجيل).

## الحالة الحالية
يوجد Edge Function جاهزة في المشروع: `supabase/functions/export-users/index.ts`.
- تقرأ من جدول `auth.users` و `public.profiles`.
- تُخرج ملف CSV يحتوي على: `id`, `email`, `created_at`, `full_name`, `username`, `account_type`.
- تتطلب Header باسم `x-export-token` للمصادقة.

## الخطوات
1. التحقق من أن الـ Edge Function `export-users` منشورة على الـ backend.
2. تشغيلها واستلام ملف `users.csv`.
3. حفظ الملف في `/mnt/documents/` لمراجعته.
4. تسليم المستخدم رابط/مسار الملف مع ملخص بعدد المستخدمين وتوزيعهم (Seeker vs Crew).

## ملاحظات
- لا يتم تعديل قاعدة البيانات، العملية للقراءة فقط.
- لا يُعرض أي بيانات حساسة مثل كلمات المرور أو المفاتيح.
- إذا أراد المستخدم لاحقًا عرض المستخدمين داخل لوحة الأدمن، يمكن تحويلها إلى صفحة Admin داخل التطبيق.
