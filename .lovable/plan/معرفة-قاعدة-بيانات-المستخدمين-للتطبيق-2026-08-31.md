# معرفة قاعدة بيانات المستخدمين للتطبيق

## الهدف
توفير طريقة واضحة لعرض / تصدير بيانات مستخدمي التطبيق (البريد الإلكتروني، الاسم، نوع الحساب، تاريخ الإنشاء) بأمان ودون كشف البيانات الحساسة.

## الخيارات المقترحة

### الخيار أ: استخدام دالة التصدير الجاهزة (الأسرع)
الدالة موجودة بالفعل في `supabase/functions/export-users/index.ts` وترجع ملف CSV.

1. فتح رابط الدالة من المتصفح أو Postman:
   ```text
   GET /functions/v1/export-users
   Header: x-export-token: superpark-dev-export-2026
   ```
2. سيُحمّل ملف `users.csv` يحتوي:
   - `id` — معرف المستخدم
   - `email` — البريد الإلكتروني
   - `created_at` — تاريخ التسجيل
   - `full_name` — الاسم الكامل
   - `username` — اسم المستخدم
   - `account_type` — نوع الحساب (seeker / crew)

### الخيار ب: إضافة صفحة "المستخدمين" داخل لوحة الإدارة (للاستخدام المتكرر)
إذا أردت مراجعة المستخدمين داخل التطبيق بدلاً من تحميل CSV في كل مرة.

1. إنشاء Edge Function آمنة (`admin-list-users`) تُرجع قائمة المستخدمين فقط لحسابات `admin`.
2. إضافة تبويب جديد في صفحة `Admin.tsx` باسم "المستخدمين".
3. عرض الجدول بالحقول نفسها مع إمكانية التصفية حسب `account_type` أو البحث بالبريد/الاسم.
4. تطبيق صلاحيات RLS بحيث لا يصل غير الأدمن إلى البيانات.

## الاستعلام الأساسي
```sql
SELECT
  au.id,
  au.email,
  au.created_at,
  p.full_name,
  p.username,
  p.account_type
FROM auth.users au
LEFT JOIN public.profiles p ON p.user_id = au.id
ORDER BY au.created_at DESC;
```

## ملاحظات أمنية
- لا تُعرض hash كلمة المرور أو أي بيانات مصادقة.
- الوصول يقتصر على الأدمن أو عبر token سري.
- لا يتطلب تغيير هيكل قاعدة البيانات (migration) في حالة التصدير فقط.
